<h3 align="center">AI4TS</h3>
<h3 align="center">building AI for unified time-series analysis</h3>

AI4TS provides open time-series data protocols, local statistical analysis, and
a Python client and CLI for the TimeSeries.AI service.

Start with the [ai4ts-cli Guidance](docs/cli-guide.md) for installation, data
inspection and preparation, local analysis, and remote service usage.
